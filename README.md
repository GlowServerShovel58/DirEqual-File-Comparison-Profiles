## Usage

### For Directory Comparison:
1. Launch DirEqual and open the **Comparison** window.
2. Load a comparison profile via **File** → **Load Profile**.
3. Select your source and target directories.
4. Apply the appropriate filter preset based on your comparison type.
5. Run the comparison and review the results in the main interface.
6. Use the results for synchronization, cleaning, or reporting.

### For File Synchronization:
1. Select a synchronization template from the collection.
2. Set your source and destination directories.
3. Configure sync direction (one-way or two-way) using the template settings.
4. Review conflict resolution rules (overwrite, skip, rename, etc.).
5. Preview the sync operations before execution.
6. Run the synchronization and monitor progress.

### For Backup Verification:
1. Load a backup verification profile.
2. Compare your original directories with backup directories.
3. Review differences to ensure backup integrity.
4. Generate a comparison report using the report template.
5. Address any discrepancies found during comparison.

### For Duplicate Detection:
1. Apply the duplicate finder profile from the collection.
2. Set the scan directory and comparison criteria (name, size, content).
3. Run the duplicate scan and review results.
4. Select duplicate files for deletion or archiving.
5. Manage duplicates using the grouped results view.

### For Automation:
1. Navigate to the **Scripts** folder in the repository.
2. Open the appropriate script file (`.bat`, `.ps1`, or `.vbs`).
3. Configure parameters (directories, profile name, output path).
4. Run the script manually or schedule it with Task Scheduler.
5. Review generated reports and logs after execution.

### For Disk Analysis:
1. Load a disk analysis profile.
2. Select the drive or directory to analyze.
3. Run the analysis to visualize file distribution and usage.
4. Use the results to identify large files, outdated data, or storage issues.
5. Take action based on the analysis findings.

### Customization Guide:
1. Load an existing profile as a starting point.
2. Modify comparison criteria (ignore timestamps, compare content, etc.).
3. Adjust filter settings to include or exclude specific files.
4. Save your custom profile with a descriptive name.
5. Document your settings for team use or future reference.
